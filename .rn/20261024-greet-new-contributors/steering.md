# Greet new contributors in the README

G1: The README greets new contributors and points them to the CONTRIBUTING file, so someone who comes to contribute knows where to start; asked for as new contributors and confirmed at the plan sign-off feedback.

## Acceptance criteria

- AC1: The README has, right below its description, one line that greets new contributors, and its link opens CONTRIBUTING.md, so a new contributor meets the greeting within the first lines and reaches the file it points to.
- AC2: CONTRIBUTING.md is a short file at the top of the repository, so the README's link leads to a file that is there.
