# Checklist for CONTRIBUTING

The reader is a new contributor who arrives from the README's link and, from CONTRIBUTING alone, makes a first change and sends it as a pull request.

The checklist asks four things, each stated as what the reader gets:

1. On opening, the reader can tell the file is for them.
2. With what they have, they make their first change by its steps.
3. They send it as a pull request and know what happens next.
4. Each statement holds when they try it.

It asks no rules of conduct or style, which the repository does not yet have.
